# 登录模块测试用例

| 编号 | 场景 | 步骤 | 预期结果 |
|---|---|---|---|
| TC-001 | 正确账号密码 | 输入 admin / 123456，点击登录 | 跳转到首页，右上角显示用户名 |
| TC-002 | 密码错误 | 输入 admin / wrong，点击登录 | 提示「账号或密码错误」，停留在登录页 |
| TC-003 | 账号为空 | 账号留空，输入密码后登录 | 提示「请输入账号」 |
| TC-004 | 密码长度边界（1 位） | 输入 admin / 1 | 提示「密码长度至少 6 位」 |
| TC-005 | 密码长度边界（32 位） | 输入 32 位合法密码 | 允许登录成功 |
